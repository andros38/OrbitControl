# Changelog

## v0.5.0

- Aplikasi difokuskan pada manajemen modem Huawei/Orbit B312.
- Menghapus Log Radio, riwayat band, ekspor CSV, dan konfigurasi penyimpanannya.
- Menghapus rekomendasi band dan evaluasi otomatis.
- Menghapus uji throughput, Speed Test, serta pembandingan Antenna A/B.
- Network Tools hanya memuat Band Lock manual, Statistik, dan Diagnosis.

## v0.4.0-personal

- Android direposisikan sebagai aplikasi pribadi Orbit Control.
- Menu pencatatan diganti menjadi Log dan halaman diberi judul Log Radio.
- Konteks aplikasi dirapikan sebagai utility modem pribadi.
- Logging radio lokal dan ringkasan per band tetap tersedia.
- Export CSV tetap mendukung Simpan CSV dan Bagikan CSV.
- Status download singkat ditambahkan ke export log.
- Throughput dan upload test tetap opsional.
- Band Lock tetap manual, memakai konfirmasi, dan diverifikasi ulang.
