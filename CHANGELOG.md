# Changelog

## v0.5.0

- Orbit Control difokuskan pada manajemen modem Huawei/Orbit B312.
- Menyediakan source code untuk Android, Windows, dan Linux.
- Mempertahankan login HiLink, dashboard, statistik, diagnosis, daftar perangkat, informasi firmware, dan Debug Report.
- Mempertahankan Band Lock LTE manual dengan konfirmasi dan verifikasi pembacaan ulang modem.
- Menghapus fitur penelitian: rekomendasi band, Log Radio/CSV, throughput/Speed Test, dan perbandingan Antenna A/B.
- Windows menghasilkan installer `.exe` dan `.msi` dengan Java runtime terbundel.
- Linux mendukung pembuatan paket `.deb` dan `.rpm`.
