# Orbit Control v0.5.0

Rilis v0.5.0 memfokuskan Orbit Control sebagai aplikasi manajemen modem **Huawei/Orbit B312** untuk Android, Windows, dan Linux.

## Fitur

- Monitoring status modem, operator, traffic, perangkat, dan metrik sinyal.
- Band Lock LTE manual dengan konfirmasi dan verifikasi.
- Statistik penggunaan.
- Diagnosis koneksi.
- Informasi firmware.
- Export Debug Report yang telah menyaring informasi sensitif.

## Download

Pilih paket sesuai platform Anda:

- **Android:** Orbit-Control-0.5.0-Android.apk
- **Windows:** Orbit-Control-0.5.0-Windows-Setup.exe
- **Windows MSI:** Orbit-Control-0.5.0-Windows.msi
- **Linux:** `.deb` / `.rpm` jika telah tersedia.

### Catatan

Orbit Control difokuskan pada Huawei/Orbit B312. Dukungan endpoint HiLink dan Band Lock dapat berbeda tergantung firmware/operator.

Band Lock merupakan fitur eksperimental. Pastikan Anda memahami konfigurasi LTE perangkat sebelum menggunakannya.
